# MPFB2 human generator — setup + build

The movement figure's body is a REAL rigged human generated by **MPFB2**
(MakeHuman Plugin for Blender). Base mesh + assets are **CC0** — ours to use
commercially, no attribution required (unlike the Z-Anatomy muscle body, which
is CC-BY-SA and stays the "Muscles" view only).

## Install MPFB2 (one-time, per machine)
MPFB isn't in the repo (44MB). Install as a Blender **extension** (4.2+/5.x):

```bash
curl -sL https://files.makehumancommunity.org/plugins/mpfb2-latest.zip -o /tmp/mpfb2.zip
EXT="$HOME/Library/Application Support/Blender/<BLENDER_VER>/extensions/user_default"
mkdir -p "$EXT" && unzip -q -o /tmp/mpfb2.zip -d "$EXT"
/Applications/Blender.app/Contents/MacOS/Blender -b --python-expr \
  "import bpy; bpy.ops.preferences.addon_enable(module='bl_ext.user_default.mpfb'); bpy.ops.wm.save_userpref()"
```
NOTE: it ships `blender_manifest.toml`, so it MUST go in `extensions/`, not
`scripts/addons/` — enabling as a plain addon fails on Blender 5.1
("package does not name an extension"). Enable module = `bl_ext.user_default.mpfb`.

## Build the human
```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P anatomy/blender/build_mpfb_human.py
```
Outputs `anatomy/out/mpfb-human.blend` (14,380-vert body + 163-bone rig) and a
T-pose `.glb`. Athletic adult male macro; helper geometry (skirt/hair/joint
cubes) stripped by deleting the `HelperGeometry` vertex group before export.

## Rig facts (for animating)
- Spine is TOP-DOWN: spine01 = upper (near neck), spine05 = base (near root).
- Legs: pelvis.L → upperleg01/02.L → lowerleg01/02.L → foot.L.
- Arms: clavicle.L → shoulder01.L → upperarm01/02.L → lowerarm01/02.L → wrist.L.
- Local **X-axis** rotation = flexion on hips/knees/elbows (verified). Our
  key_pose auto-detects flex signs, so the pose math ports directly.
